Injects the multi-genre filter button into the web client's filter panel. The intersection endpoint stays available either way — turning this off only removes the button, so it is the recovery step if a Jellyfin web-client upgrade ever breaks the page: untick this and the client goes back to stock without uninstalling the plugin. Takes effect on the next page load.
A guard rail, not a page size. If a single genre resolves to more items than this, the request is refused with an error rather than truncated. A truncated genre list would still intersect to a plausible-looking number that is simply wrong, which is worse than failing.
How many items to return when a request does not ask for a specific page size.
